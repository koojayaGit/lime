화면별 상세 명세: [013_Discovery.md](013_Discovery.md)

- 관심 기업을 Research의 `companies`와 분리된 `discovery_companies` 테이블에 저장한다.
- 관심 기업 추가·수정·삭제, 발굴 이유, 검토 상태, 등록일을 관리한다.
- 성장 단계를 씨앗주·새싹주·성장주·기둥주·열매주 중 선택할 수 있다.

- Supabase SQL Editor에서 `supabase/setup_discovery.sql`을 한 번 실행해야 추가·수정·삭제가 가능하다.

## 데이터 출처와 제한

미국 종목의 현재가와 펀더멘털은 Finnhub에서 조회한다. 국내 종목의 현재가는 Yahoo Finance, 펀더멘털은 네이버 금융에서 조회한다. 조회한 펀더멘털은 Discovery에 저장하며 기존 값 일부가 있는 종목은 자동으로 덮어쓰지 않는다. 국내 펀더멘털 경로는 네이버 금융 웹 앱의 비공식 인터페이스를 사용한다.

### Finnhub 무료 호출 한도와 관심종목 규모

- Finnhub 무료 API는 분당 최대 60회 호출 한도를 기준으로 사용한다. 한도는 종목별이 아니라 같은 API 키로 발생한 요청 전체에 적용된다.
- 지표 자동 조회는 호출 간격을 두고 순차 처리한다. 현재가 조회는 종목 카드별로 최초 요청하고 10분 간격으로 갱신하므로, 관심종목이 많으면 화면을 처음 열 때 요청이 몰려 한도 초과(429)가 발생할 수 있다.
- 관심종목 100개 규모를 안정적으로 지원하려면 현재가 요청도 순차화·분산하고 서버 캐시를 두어 같은 종목을 여러 사용자가 반복 조회하지 않게 해야 한다. 이 현재가 호출 제어와 서버 캐시는 아직 구현하지 않았다.
- 배포 환경에서는 Vercel Production 환경변수 `FINNHUB_API_KEY`를 설정했으며, 설정 후 재배포했다.
- 모바일에서 현재가가 조회되지 않는 현상이 있었으나 로그아웃 후 다시 로그인하자 정상화됐다. Supabase 로그인 세션 만료 또는 세션 갱신 문제일 가능성이 있다.
- 후속 작업: 세션 만료나 시세 조회 실패 때 사용자가 쉽게 복구할 수 있도록 화면에 새로고침/재시도 기능을 추가하고, 필요하면 재로그인 안내를 제공한다. 아직 구현하지 않았다.

## Portfolio

- 보유 종목과 통화별 현금을 직접 입력·수정·삭제한다. 보유 종목은 국가와 거래소에 맞춰 시세를 조회하고 데이터 출처와 기준 시각을 표시한다.
- Portfolio 요약은 주식 평가액과 현금을 합산한다. 손익·수익률은 현금을 제외한 주식 기준으로 계산한다.
- 모든 현재가와 필요한 환율을 가져온 경우에만 총자산과 전체 비중을 계산한다. 일부 가격이 누락되면 합계를 확정값으로 보여주지 않는다.
- 보유 종목에 씨앗주·새싹주·성장주·기둥주·열매주 단계를 지정한다. 성장 단계별 주식 평가액 비중은 현금을 빼고 계산하며, 큰 비중 순으로 그래프와 범례에 표시한다. 기존 단계 미지정 종목은 `미분류`로 모아 표시한다.
- Holdings 표와 자산 비중 그래프는 모바일·데스크톱 화면을 지원한다.
- 현재는 거래 체결 내역을 저장하지 않는다.
- 데이터는 사용자별 Supabase 테이블과 RLS로 분리하고 Realtime 동기화한다. 기존 프로젝트에는 업데이트된 `supabase/setup_portfolio.sql`을 다시 적용하거나 `20261111000000_add_portfolio_growth_stage.sql`을 실행해 성장 단계 컬럼을 추가한다.
- 화면 상세: [015_Portfolio.md](015_Portfolio.md)
